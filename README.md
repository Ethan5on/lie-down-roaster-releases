# LIE DOWN Roaster 사용 설명서

Giesen W1A · W6A용 로스팅 기록 · 자동 제어 프로그램(맥 앱)입니다. 이 저장소에는 설치 파일만 있고 소스 코드는 없습니다.

- **내려받기**: [최신 버전](https://github.com/Ethan5on/lie-down-roaster-releases/releases/latest)의 `LIE-DOWN-Roaster-버전.dmg` (또는 `.zip`)
- **필요한 것**: macOS 14 이상, 로스터와 연결할 랜선
- **바뀐 내용**: 각 릴리스 설명, 또는 앱의 **설정 → 프로그램 정보 → 업데이트 내역**

> 어떤 경우에도 **로스터의 비상 정지와 패널 조작이 이 프로그램보다 우선합니다.** 자동 제어 중에도 로스터 곁을 떠나지 마세요.

---

## 1. 설치

1. `.dmg`를 열고 **LIE DOWN Roaster** 아이콘을 옆의 **Applications** 폴더로 끌어 놓습니다.
   - `.zip`을 받았다면 압축을 풀고 앱을 **응용 프로그램** 폴더로 옮깁니다.
2. 처음 열 때 "확인되지 않은 개발자" 경고가 나옵니다. 앱 스토어를 거치지 않은 앱이라서입니다.
   - 응용 프로그램 폴더에서 앱을 **우클릭 → 열기**를 합니다.
   - 그래도 막히면 **시스템 설정 → 개인정보 보호 및 보안** 맨 아래의 **그래도 열기**를 누릅니다.
   - 그래도 안 되면 터미널에서 아래 명령을 한 번 실행한 뒤 다시 엽니다.
     ```bash
     xattr -dr com.apple.quarantine "/Applications/LIE DOWN Roaster.app"
     ```
3. 로스터에 처음 연결할 때 macOS가 **로컬 네트워크** 접근을 묻습니다. **허용**하세요. 거부했다면 **시스템 설정 → 개인정보 보호 및 보안 → 로컬 네트워크**에서 켭니다.

## 2. 라이선스

컴퓨터마다 라이선스 파일이 있어야 로스팅과 로스터 연결을 쓸 수 있습니다. 라이선스가 없으면 **보기 전용**입니다(기록 · 생두 · 프로파일 보기만 가능).

1. 앱을 켜고 **로스팅** 탭을 열면 "라이선스가 필요합니다" 화면에 **기기 번호**가 나옵니다. **복사**를 눌러 개발자에게 보냅니다.
2. 개발자에게 받은 라이선스 파일(`.json`)을 같은 화면의 **라이선스 파일 불러오기…**로 고릅니다.
3. 만료일은 없습니다. 라이선스는 그 맥에서만 동작하므로, 맥을 바꾸면 새 기기 번호로 다시 받아야 합니다.

**설정 → 프로그램 정보 → 버전 · 라이선스**에서 라이선스 이름과 기기 번호를 다시 볼 수 있습니다.

## 3. 업데이트

- 프로그램을 켤 때마다 새 버전을 확인하고, 있으면 바뀐 내용을 보여 주며 업데이트할지 묻습니다.
- 개발자 서명이 맞는 파일만 설치합니다. 받기 · 확인 · 설치 과정은 게이지로 보입니다.
- **로스팅 중에는 업데이트하지 마세요.** 배출하고 로스팅을 종료한 뒤 업데이트합니다.
- 새 버전은 `~/Library/Application Support/LIE DOWN Roaster/app` 폴더에 설치되고, Dock이나 응용 프로그램 폴더의 아이콘으로 켜도 가장 새 버전이 열립니다.
- 직접 확인하려면 **설정 → 프로그램 정보 → 업데이트**를 누릅니다.

## 4. 처음 로스터에 연결하기 (꼭 이 순서대로)

1. 맥과 로스터를 랜선으로 연결합니다. 로스터 패널의 네트워크 설정에서 로스터 IP를 확인하고, 맥의 **시스템 설정 → 네트워크 → 이더넷**을 **수동**으로 바꿔 같은 대역의 IP를 넣습니다. 예: 로스터가 `172.30.30.30`이면 맥은 `172.30.30.42`, 서브넷 `255.255.255.0`.
2. Firescope, Artisan 등 **다른 로스팅 프로그램은 종료**합니다. 두 프로그램이 동시에 화력을 바꾸면 위험합니다.
3. 왼쪽 메뉴의 **로스터**(⌘5)에서 `Giesen W1A`를 고릅니다. 다른 모델(W6A)이거나 로스터가 여러 대면 **로스터 추가**로 모델을 골라 추가합니다. 이름 · IP(1번에서 확인한 로스터 IP) · 포트(`102`)를 넣고 **연결**을 누릅니다.
4. **연결 점검** 표에서 두 온도 값(W1A는 `DB3.114` / `DB3.118`, W6A는 `DB3.112` / `DB3.116`)을 로스터 패널의 원두 온도(BT)와 비교합니다. BT와 같은 쪽을 고르고 **확인했습니다**를 누릅니다.
   - 화력 %, 내압 Pa, 드럼 Hz도 패널과 같은지 확인하세요. 다르면 사용을 멈추고 개발자에게 알려 주세요.
5. 여기까지는 **읽기 전용**이라 로스터에 아무것도 쓰지 않습니다. 기록만 할 때는 이 상태로 써도 됩니다.
6. 제어를 쓰려면 빈 드럼으로 예열하는 동안 **제어 허용**을 켭니다. 화력을 1~2% 바꿔 보고 패널 값이 따라 바뀌는지 확인하세요. 내압과 드럼도 같은 방법으로 확인합니다.

**로스터가 여러 대일 때**: 로스터마다 IP, 연결 점검, 에너지 · 원가 설정을 따로 기억합니다. 다른 로스터를 고르고 **연결**을 누르면 바뀌며, 바꿀 때마다 **제어 허용**은 꺼지므로 다시 켜야 합니다. W6A는 온도 주소가 달라서 연결 점검 표에 `DB3.112` / `DB3.116`이 나옵니다(W1A는 `DB3.114` / `DB3.118`). 로스터를 추가할 때 모델을 맞게 고르고, 처음에는 4~6번 확인을 꼭 다시 하세요.

**연습하기**: 장치를 **시뮬레이터**로 바꾸면 로스터 없이 가상 로스터로 모든 기능을 연습할 수 있습니다(5~20배 속도 가능).

## 6. 로스팅

### 시작과 끝
- 오른쪽 패널 맨 위 **▶ 로스팅 시작**을 누르면 예열 · 로스팅 · BBP를 끊김 없이 기록합니다. **■ 로스팅 종료**로 기록을 멈춥니다(배출한 뒤에 가능).
- **예열**을 시작하거나 **투입**하면 기록이 자동으로 시작됩니다.
- 배치 기록 범위: 첫 배치는 로스팅 시작 ~ 배출(예열 포함), 그다음부터는 이전 배출 ~ 이번 배출(BBP 포함)입니다.

### 배치 정보
- 그래프 위의 알약에서 **생두**, **레퍼런스**(비교 곡선), **화력 프로파일**을 고릅니다. 고르지 않았으면 "생두 없음"처럼 보입니다.
- 오른쪽 패널의 배치 정보 칸에서 이름과 투입량을 정합니다. 로스팅 중에 고쳐도 그 배치에 바로 반영됩니다.

### 이벤트
- **투입**: BT가 갑자기 떨어지면 자동으로 감지합니다. 버튼(또는 ⌃C)으로 직접 해도 됩니다. 잘못 감지됐으면 **투입 취소**를 누릅니다.
  - 배출 직후에는 도어를 열어 온도가 떨어지는 동안 잘못 감지하지 않도록 정해진 시간(기본 120초) 동안 자동 감지를 쉽니다.
- **터닝포인트, 드라이엔드**: 자동으로 표시됩니다.
- **1차/2차 크랙**: 버튼이나 단축키로 표시합니다. 한 번 더 누르면 지워집니다.
- **배출**: 기록이 저장되고, 생두 재고가 투입량만큼 자동으로 차감됩니다. '방금 배출' 줄에 배출량을 넣으면 감량률이 계산됩니다.
- **이벤트 목록**(제어 패널 아래): 투입 · 배출 · 화력 변경 · 모드 변경 · 경고 등이 시간 순서로 남고, 배치 기록에도 저장됩니다.

### 그래프
- BT/ET 곡선, RoR, 화력 · 내압 · 드럼, 건조 · 메일라드 · 디벨롭 비율, DTR이 보입니다. 레퍼런스를 고르면 점선으로 겹쳐 보입니다.
- 그래프 오른쪽 위 버튼:
  - **돋보기**: 지금 시점을 가운데 두고 2배 → 4배, 세 번째에 원래대로
  - **전체화면**: 그래프를 크게 보고 위쪽에 시간 · BT · ET · RoR · 화력을 큰 글씨로 표시(Esc로 닫기)
  - **그래프 설정**: 축 범위, 그래프 시간 폭(분), RoR 계산 구간(15/30/60초), 그리드, 선 색 · 두께 · 모양, 구간 색
- 그래프 시간 폭을 10분으로 정하면 투입 전에도 10분 폭으로 보이고, 로스팅이 더 길어지면 축이 늘어납니다.
- 오른쪽 패널과 제어 패널은 경계선을 끌어 넓힐 수 있습니다(더블클릭하면 원래 크기).

### 화력 · 내압 · 드럼
- **숫자 버튼**(5% 단위)이나 **세로 게이지**(끌어서 1% 단위, 손을 떼면 적용)로 바꿉니다.
- 큰 화력 숫자, 내압, 드럼 숫자를 클릭하면 직접 입력합니다(내압 80~150 Pa, 드럼 35~60 Hz).
- **AUTO**는 로스터 자체의 자동 화력으로 넘깁니다. 이때 이 프로그램의 자동 제어는 꺼집니다.

### 긴급 종료
- 로스팅 중에는 맨 위 버튼이 빨간 **■ 긴급 종료**로 바뀝니다. 누르면 묻지 않고 바로:
  - 모든 자동 제어를 끄고, **화력 0%**, **내압 최대(150 Pa)**로 냉각 바람을 최대로 줍니다. 드럼은 계속 돕니다.
  - 그 시점까지 배치를 저장하고(메모에 '긴급 종료'), 기록을 종료합니다.
- **배출구는 프로그램이 열 수 없습니다.** 로스터에서 직접 배출하고 냉각하세요.
- 명령을 보내지 못하면(연결 끊김 · 제어 허용 꺼짐) 빨간 경고가 뜹니다. 패널에서 직접 화력을 끄세요.

## 7. 자동 제어

제어 패널 위의 **수동 / 자동** 버튼으로 고릅니다. 자동은 그래프 위에서 고른 것에 따라 동작이 달라집니다.

| 고른 것 | 자동 버튼 | 하는 일 |
|---|---|---|
| 화력 프로파일만 | **프로파일** | 프로파일 단계대로 화력 · 내압 · 드럼을 바꿉니다. |
| 화력 프로파일 + 레퍼런스 | 한 번 누르면 **프로파일**, 한 번 더 누르면 **프로파일 + 보정** | 프로파일대로 가면서, 터닝포인트 이후 BT가 레퍼런스 곡선을 따라가도록 화력을 프로파일 값에서 ±15% 안에서만 보정합니다. |
| 레퍼런스만 | **레퍼런스 재생** | 레퍼런스 로스팅에서 했던 화력 · 내압 · 드럼 변경을 같은 시점(또는 같은 BT)에 그대로 따라 합니다. |

- 버튼 오른쪽 끝의 **세로 동그라미 두 개**가 상태를 보여 줍니다. 아래만 채워지면 프로파일, 둘 다 채워지면 프로파일 + 보정입니다.
- 로스팅 전에 자동을 켜 두면 **투입하는 순간 시작**합니다. 로스팅 중에 바꾸면 바로 적용됩니다.
- 화력 · 내압 · 드럼을 손으로 바꾸거나 로스터 패널에서 바꾸면 자동 제어가 꺼집니다.
- **Esc를 1초 안에 두 번** 누르면 모든 자동 제어가 즉시 꺼집니다. 화력은 그 값 그대로 유지됩니다(긴급 종료와 다릅니다).
- **설정 → 안전 · 자동 제어 → 자동 제어 기능**에서 프로파일 · 프로파일 + 보정 · 레퍼런스 재생을 각각 켜고 끌 수 있습니다(기본은 모두 켜짐). 보정 폭과 보정 세기도 같은 페이지에서 바꿉니다.

## 8. 프로파일

왼쪽 메뉴 **프로파일**에서 만듭니다. 로스팅 · BBP · 예열 프로파일이 한 목록에 있고, 카드의 **ON / OFF**로 쓸 것을 정합니다(종류마다 하나).

**로스팅 프로파일**
- 단계마다 기준(시간 또는 BT), 시점(`1:30` 또는 `150`), 화력 · 내압 · 드럼을 적습니다. 비워 둔 칸은 바꾸지 않고, 화력 `-1`은 로스터 AUTO입니다.
- 단계는 위에서부터 차례로 실행됩니다. BT 단계는 터닝포인트 이후에만 동작합니다.
- **기록에서 가져오기**로 지난 로스팅의 화력 변경을 단계로 불러올 수 있습니다.

**BBP 프로파일** (배출 후 다음 투입까지)
1. 배출 후 시간에 따라 화력 · 내압 · 드럼을 바꿉니다.
2. 그다음 기준 온도(BT 또는 ET)가 정한 온도에 도달하면 바꿉니다.
3. 투입 온도 **N°C 전**과 **도달**했을 때 소리로 알립니다. 도달한 뒤 그 온도를 유지할 수도 있습니다.
- **설정 → BBP · 예열**에서 **배출하면 BBP 자동 시작**을 켜 두면 배출하는 순간 시작합니다.

**예열 프로파일** (처음 로스터를 켰을 때)
- 몇 도를 몇 분 유지할지 단계로 정합니다(예: 220°C 30분 → 205°C 10분). 목표 온도에 도달한 순간부터 시간을 셉니다.
- 단계마다 알람(도달 / 끝 / 둘 다)을 고르고, 모든 단계가 끝난 뒤 '마지막 온도 유지' 또는 '정한 화력으로 바꾸고 끄기'를 고릅니다.
- 시작하면 먼저 로스터 AUTO로 점화를 기다리고, 버너가 반응하면 프로파일을 이어받습니다.

로스팅 화면 PHASE 아래의 **예열 / BBP** 버튼으로 실행하고, 한 번 더 누르면 끕니다.

## 9. 안전장치

- 처음 연결하면 읽기 전용입니다. 연결 점검과 제어 허용을 모두 마쳐야 값을 씁니다. 장치를 바꾸면 제어 허용이 다시 꺼집니다.
- 쓰는 값은 항상 범위 안으로 제한됩니다: 화력 0~100%, 내압 80~150 Pa, 드럼 35~60 Hz.
- 로스터 패널이나 다른 프로그램에서 값이 바뀐 것을 감지하면 자동 제어를 바로 끕니다.
- BT나 ET가 설정한 상한(기본 235°C / 320°C)을 넘으면 경고하고 자동 제어를 끄고 화력 0%를 명령합니다.
- 통신이 끊기면 자동 제어를 끄고 경고합니다. 이때 **로스터는 마지막으로 받은 값을 유지**하므로 패널에서 직접 확인하세요.

## 10. 생두 · 기록 · 원가

**생두**
- 싱글 오리진 / 블렌드 탭, 재고 막대, 재고 자산(재고 × 단가)이 보입니다.
- **재입고**: 입고량과 단가를 넣으면 재고와 가중평균 단가가 갱신됩니다. **출고 · 손실 기록**으로 줄입니다.
- **CSV 가져오기**: 열 이름은 이름, 원산지, 농장, 품종, 가공, 수확연도, 재고(kg), 단가, 공급사, 메모입니다.
- **블렌드**: 싱글 오리진을 골라 비율(합계 100%)을 정합니다. 배출하면 각 생두 재고가 비율대로 차감됩니다.
- 생두나 블렌드에 화력 프로파일을 연결해 두면, 그 생두를 고를 때 프로파일이 같이 선택됩니다.

**기록**
- 검색, 즐겨찾기, 두 로스팅 겹쳐 보기, CSV 내보내기, 레퍼런스 지정을 합니다.
- **목록 설정**에서 카드에 보일 항목(투입, 감량, 시간, 1차, DTR, 생두 비용, 에너지 비용 등)과 순서를 고릅니다.
- **예열 / BBP 같이 보기**: 그 배치 직전의 예열 · BBP를 그래프 0:00 앞쪽에 이어서 보여 줍니다.
- 목록을 숨기면 고른 배치를 크게 보고, ← / → 로 다른 배치로 넘어갑니다.
- **커핑하기**: 배치 상세에서 점수와 향미(향미 휠)를 남깁니다.

**원가**
- 배치마다 **생두 비용**과 **에너지 비용**(투입 전 예열 · BBP의 연료 · 전기 포함)을 계산합니다.
- 연료 종류와 단가는 **로스터 → 에너지 · 원가**에서 정합니다. LPG는 용기 무게를 두 번 재면 화력 100%일 때 시간당 사용량을 자동으로 구합니다.

## 11. 단축키

로스터를 움직이는 키는 모두 control(⌃)이나 option(⌥)과 같이 눌러야 해서, 글자를 치다가 잘못 눌릴 일이 없습니다. 글자 입력 칸에 커서가 있거나 창이 열려 있으면 동작하지 않습니다.

| 키 | 동작 |
|---|---|
| ⌃N | 다음 이벤트 (투입 → 드라이엔드 → 1차 크랙 → 1차 끝 → 2차 크랙 → 배출) |
| ⌃C / ⌃D / ⌃F / ⌃E / ⌃S / ⌃X | 투입 / 드라이엔드 / 1차 크랙 / 1차 끝 / 2차 크랙 / 배출 |
| ⌥↑ / ⌥↓ | 화력 +1% / −1% (⇧를 같이 누르면 ±5%) |
| ⌃H | 제어 패널 숨기기 / 보이기 |
| Esc Esc | 1초 안에 두 번: 모든 자동 제어 끄기 (현재 값 유지). 한 번은 창 닫기만 |
| ⌘1 ~ ⌘5, ⌘, | 로스팅 · 프로파일 · 기록 · 생두 · 로스터 · 설정 |
| ⌘Q | 프로그램 종료 (기록 중이면 한 번 더 묻습니다) |

## 12. 데이터와 백업

- 기록 · 생두 · 커핑 · 프로파일은 **이 맥에만** 저장됩니다. 다른 컴퓨터와 동기화하지 않고, 인터넷으로 보내지 않습니다.
- 저장 위치는 **설정 → 데이터 → 데이터 폴더**에서 보고 바꿀 수 있습니다. **백업하려면 이 폴더를 복사**하세요.
- **모든 데이터 지우기**도 같은 페이지에 있습니다. 지운 내용은 데이터 폴더 옆 'LIE DOWN Roaster backup 날짜' 폴더로 옮겨 두니 되살릴 수 있습니다.
- 화면 모드(라이트 / 다크), 무게 단위(kg / g), 언어(한국어 / English), 알람 소리는 **설정 → 화면 · 소리**에서 바꿉니다.

## 문제가 생기면

- **"확인되지 않은 개발자"로 열리지 않음**: 1. 설치의 2번을 보세요.
- **로스터에 연결되지 않음**: 이더넷 IP(172.30.30.42)와 로컬 네트워크 허용을 확인하세요. 다른 로스팅 프로그램이 켜져 있으면 끄세요.
- **로스팅 버튼이 없고 기기 번호가 보임**: 라이선스가 없습니다. 2. 라이선스를 보세요.
- **업데이트가 끝나지 않음**: 프로그램을 종료했다가 다시 켜 보세요. 그래도 안 되면 `~/Library/Logs/LIE DOWN Roaster/update.log` 파일을 개발자에게 보내 주세요.
